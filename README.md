🌌 ZenBlocks: Matrix Shift
Un joc de puzzle rapid și minimalist cu estetică Cyberpunk / Neon-Noir, construit în TypeScript și randat direct în HTML5 Canvas. Combină mecanica clasică de așezare a blocurilor cu strategii moderne și efecte vizuale retro-arcade.

✨ Ce are special?
🕹️ 3 Moduri de joc: Campaign (8 nivele progresive cu obiective și timp limită), Endless (relaxare completă) și Custom Matrix (îți configurezi singur regulile).

⚛️ Noduri Titan: Piese speciale purpurii care explodează cu un mega-bonus de puncte.

🌀 Zen Secret: Formezi un pătrat perfect de 3×3 în grilă pentru un impuls masiv de scor.

🪐 Gravity Shift: O mecanică unică de gravitație (Nivelul 5) unde blocurile cad în goluri și pot crea reacții în lanț.

📱 Multi-platform: Control fluid prin Drag & Drop, optimizat complet pentru mouse și ecrane tactile.

🛠️ Stack Tehnic
TypeScript (OOP, tipizare strictă)

HTML5 Canvas API (randare 2D rapidă, la 60 FPS)

CSS3 Variables & Animations (efecte de glitch, linii CRT și strălucire neon)

🚀 Pornire rapidă
Bash
git clone https://github.com/utilizator/zenblocks.git
cd zenblocks
npm install
npm run dev
